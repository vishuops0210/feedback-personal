# 📸 Photo Folders

Don't create custom names. Just drop your photos into the folders below with the exact
file name written here. Everything is already wired up.

## Monthly Photos → `public/images/monthly/`

Drop the photo named `june-2026.png` into this folder for it to show on the June 2026 slide.

| File name | Shows on |
|-----------|----------|
| `june-2026.png` | June 2026 |
| `july-2026.png` | July 2026 |
| `august-2026.png` | August 2026 |
| `september-2026.png` | September 2026 |

_(Aage ke months abhi list mein nahi hai — jab add karo, tab tak sirf September tak dikhte hain.)_

## Rules of thumb
- **PNG is expected** — if you have a JPG, rename it to `.png` when dropping it in
  (or tell me and I'll change the extension everywhere).
- **Don't touch the JSON files** — the paths are already filled in.
- If a photo is missing, the site shows a friendly "No image provided yet" box —
  nothing breaks.
